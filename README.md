# Student Registration Management System

## Overview

This project was developed as part of the Data Structures course.

It implements a Student Registration Management System in C using AVL Trees, Linked Lists, and Hash Tables. The system allows managing student records, course registrations, searching, updating, deleting, and saving data efficiently.

---

## Features

- Load student registrations from file
- Insert new student registrations
- Update student information
- Search students by name
- Delete course registrations
- Display students enrolled in the same course
- Store records using AVL Trees
- Manage student records using Hash Tables
- Save and reload data from files

---

## Data Structures

- AVL Tree
- Linked Lists
- Hash Table
- Linear Probing
- Dynamic Memory Allocation
